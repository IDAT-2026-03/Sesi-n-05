1. Jerarquía (h1-h6)

Los encabezados organizan el contenido por importancia. Nunca los uses solo para cambiar el tamaño del texto.

HTML5 Editor
<h1>Título Principal</h1>
<h2>Subtítulo de Sección</h2>
<h3>Detalle Específico</h3>

2. Listas (ul)

Usamos <ul> para elementos donde el orden no es relevante (viñetas).

Estructura UL
<ul>
  <li>Accesibilidad</li>
  <li>Semántica</li>
  <li>SEO</li>
</ul>
  • Accesibilidad
  • Semántica
  • SEO

3. Listas (ol)

Usamos <ol> para procesos, tutoriales o cualquier secuencia lógica numerada.

Estructura OL
<ol>
  <li>Analizar</li>
  <li>Maquetar</li>
  <li>Codificar</li>
</ol>
  1. 1 Analizar
  2. 2 Maquetar
  3. 3 Codificar
